Sterlite_wiki · under the hood

What actually happens when you type "ingest"

Your wiki has no hidden machinery. It is a folder of text files, one rulebook, and a Claude session that reads and writes those files when you ask. This page takes each moving part apart so you can see it, then shows where to change it.

You: choose sources, give instructions, approve Claude: reads and writes files Obsidian: displays the files, changes nothing

        The one thing to rememberEverything Claude reads stays in the session's memory until the session ends. One transcript adds roughly 100k. Ten ingests in one session gets you to the 900k+ you saw. The wiki files themselves never fill up, so a new session starts at almost zero and loses nothing.
        Question 2 · how are folders created?

        CLAUDE.md is the blueprint; Claude does the building

        A folder is just a folder on your disk. Nobody creates folders automatically. In Step 7 of the setup you asked Claude to read the folder map in CLAUDE.md and build it, and Claude created each folder with a file-system command. Since then, Claude puts each new file wherever the map says that type of page belongs.

      Question 3 · what drives the filling?
      
            Four inputs decide what gets written, and where
            
    
            
    
            
      
            1 · The source
            What the document actually says. Claude can only write what's in it, and your rules tell it to cite the page.
            
      
            2 · The rules
            CLAUDE.md tells Claude what to look for (numbers, promises, contradictions) and which page each kind of finding goes to.
            
      
            3 · The existing wiki
            Claude reads the current pages first. Existing topic: update the page. New topic: create one. Disagreement: flag it.
            
      
            4 · Your steering
            At the "wait for my OK" checkpoint you choose what to emphasise or skip. That's where your judgement goes in.
            
    
            
    
            Pick a document type to see which rules trigger and what each one writes. Obsidian, folder names and file names don't drive any of this. If a rule doesn't ask for something, it usually won't get written.

      Question 4 · how are nodes created?
      
            A node is a file. A line is a [[link]].
            
      
            
        
            Obsidian's graph has no data of its own. It draws one dot for every .md file and one line for every [[wikilink]] inside a file. So a new node appears exactly when Claude saves a new page, and a new line appears when Claude writes a link.

            Why some names never became pagesWithout a threshold rule, Claude writes names as plain text, so nothing appears in the graph. Lint then reports them as "frequently mentioned names without a page", which is what happened with Lakshya, STL Digital, ICRA, Speedon and the US subsidiary. Adding the rule (see the next section) makes Claude create those pages during ingest.
