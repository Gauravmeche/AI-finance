## LLM Wiki for equity research

`llm-wiki-equity-research/` holds a beginner's guide to building a Karpathy-style LLM Wiki on one listed company using Claude and Obsidian:

- `guide.html`: interactive step-by-step setup guide
- `CLAUDE.md`: the schema (rulebook) template to drop into your Obsidian vault
